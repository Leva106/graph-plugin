# Graph Plugin (Figma, dev)

Локальный Figma-плагин: генерирует фреймы графиков в стиле ECharts из нативных слоёв Figma —
линейный, столбчатый (вертикально / горизонтально), круговая / кольцевая, точечная, радар;
цвета привязаны к **локальным variables** дизайн-системы (`chart/*`, `system/graphite/*`), текст — к локальным text styles.

## Запуск
```bash
npm install
npm run dev      # сборка + watch (dist/code.js, dist/ui.html)
```
Figma Desktop → Plugins → Development → **Import plugin from manifest…** → выбрать `manifest.json`.

Другие команды: `npm run build`, `npm run typecheck`, `npm test` (проверки математики в `src/core`),
`node scripts/serve.mjs` — открыть UI в обычном браузере на http://localhost:5174 (без Figma API).

## Токены
`tokens/*.tokens.json` — экспорт variables из Figma. `npm run tokens` генерирует `src/theme/tokens.generated.ts`
(имя → VariableID + hex light/dark). При создании графика переменная ищется: по VariableID → по имени
`chart/indigo/500` → по имени без верхней группы (`indigo/500`). Не нашлась — вставляется hex, плагин об этом сообщает.
После обновления токенов положите новые json в `tokens/` и пересоберите.

## Архитектура
```
src/shared/types.ts     ChartSpec v3 — контракт между источниками данных, UI и рендерерами (близок к echarts option)
src/shared/migrate.ts   старые спеки из pluginData → текущая версия
src/data/               источники данных: random.ts, table.ts (своя таблица), csv.ts (дальше llm.ts → тот же ChartSpec)
src/core/               чистая математика: nice-scale, пути, core/layout/* — геометрия каждого типа графика
src/theme/echarts.ts    ThemeSpec: размеры/отступы/токены — другой визуал = другой ThemeSpec
src/figma/              рендер в Figma: render.ts (фрейм, заголовок, легенда), cartesian.ts, polar.ts
src/ui/                 Preact UI + SVG-превью (использует тот же core/layout)
```
## Данные
Вкладка «Данные» → «Случайные» (генерация) или «Таблица» (свои значения). В таблицу можно вставить диапазон
из Excel / Google Sheets в любую ячейку — таблица расширится; первая строка без чисел станет названиями серий.
«CSV…» открывает окно с текстом данных: скопировать, вставить (Ctrl/Cmd+V), открыть файл (`,` `;` Tab, UTF-8 или
Windows-1251), скачать. Изменения проверяются (ошибки и предупреждения с номерами строк) и применяются только по «Применить».
В случайных данных «Точки: Авто» — 7 для дней недели, 12 для месяцев, для дат и 1…N — сколько подписей помещается по ширине.
Колонка 1 — категории (для точечной — значения X), дальше по колонке на серию, пустая ячейка = нет значения.

Данных может быть больше, чем подписей помещается на оси: график рисует **все** точки, а подписи/деления оси
категорий прореживаются по размеру фрейма (как `axisLabel.interval: 'auto'` в ECharts); делений оси значений
меньше на низком графике. Размер задаётся на вкладке «Данные» до создания.

## Пресеты и вставка в фрейм
Кнопка-закладка рядом с типом графика — пресеты: сохранить текущий график (данные, вид, размер) и потом выбрать его,
чтобы настроить иначе; удаляются вторым кликом по «×». Хранятся в `figma.clientStorage` (доступны во всех файлах).
Если выделить обычный фрейм (плейсхолдер в макете), появится «Вставить в «Frame»» — график встанет внутрь и будет
тянуться вместе с фреймом.

## Пересборка
Спека графика хранится в `pluginData` фрейма (`chartSpec`). Выделите график (или любой слой внутри) при открытом
плагине — настройки подгрузятся, кнопка «Обновить график» перерисует **тот же** фрейм (позиция, имя, id сохраняются),
«Создать новый» — сделает копию с новыми настройками. Данные не меняются, пока не нажать «Сгенерировать» или не поменять параметры генерации.

## Адаптивность
Фрейм можно тянуть руками: `Plot` растягивается (constraints STRETCH), линии/заливки/сетка масштабируются (SCALE),
точки и подписи лежат в маленьких якорных фреймах — едут за данными, но не искажаются. Заголовок и легенда центрированы,
ось Y прибита слева, ось X — снизу. Круговая и радар тянутся так же (при непропорциональном resize круг становится
овалом, с Shift — остаётся кругом). Прозрачность заливок — layer opacity слоя `Area`. Шаг делений и прореживание подписей при ручном resize не пересчитываются — для этого «Обновить график»
(плагин берёт текущий размер фрейма).
